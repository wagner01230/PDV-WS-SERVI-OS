ℹ️ Sobre a Sincronização em Nuvem

Este sistema funciona localmente no navegador. Os dados são armazenados no IndexedDB do seu dispositivo. A sincronização entre celulares, tablets e computadores ainda não está configurada. Será necessário implementar um backend (servidor) ou banco de dados na nuvem para que os dados sejam compartilhados entre dispositivos. O código já está preparado com a camada StorageService e pontos de integração para receber essa funcionalidade futuramente.
